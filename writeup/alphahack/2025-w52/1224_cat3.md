# cat3

## 問題の要点

- `cat` コマンドの引数として入力できるが、3文字制限がある。
- shell を経由しているため、短い shell 構文が使える。

## 解き方

`|sh` の3文字を入れると、前段の出力を shell に流せる。

```text
|sh
```

## 知見

- 短い入力制限では「単体で完結する payload」ではなく、shell の制御文字や既存 stdin/stdout を利用する。
- `|sh`, `sh`, `$0`, `*`, `?`, `<` など、短い shell gadget を候補にする。
