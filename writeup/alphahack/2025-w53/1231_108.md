# 108

## 問題の要点

- 説明文は `quiet, calming tradition`。
- challenge server を見ると、flag が Cookie に入っている。

## 解き方

ブラウザの DevTools、または HTTP レスポンス/リクエストの Cookie を確認する。

```text
Cookie: ...
```

## 知見

- Misc/Web の easy 問では、HTML 本文だけでなく Cookie、localStorage、sessionStorage、response headers を見る。
- 「静かな」「見るだけ」の問題文は、状態保存やメタデータの観察を示唆していることがある。
