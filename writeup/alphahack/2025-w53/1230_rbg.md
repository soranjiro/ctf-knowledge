# RBG

## 問題の要点

- 同じ `m, N` に対して、指数 `e_i` を LCG `e_{i+1} = 3e_i + 1337 mod N` で更新し、`c_i = m^{e_i} mod N` を 13 個出力する。
- `N` は 137-bit prime 2個の積で、`e_i` は不明。

## 解き方

隣り合う暗号文の関係を見る。

```text
c_{i+1} = m^{e_{i+1}}
        = m^{3e_i + 1337 - k_i N}
        = c_i^3 * m^1337 * (m^N)^(-k_i)  mod N
```

ここで `X = m^1337`, `Y = m^N` と置くと、

```text
A_i = c_{i+1} * c_i^(-3) = X * Y^(-k_i)
```

`k_i` は `0..3` 程度に限られる。候補から `X, Y` を復元し、`X^N == Y^1337` で整合性を確認する。
最後に `1337a + Nb = 1` を満たす `a, b` を拡張 Euclid で取り、

```text
m = X^a * Y^b mod N
```

を計算する。

## 知見

- RSA は指数が未知でも、指数同士に線形関係があると暗号文比から情報が出る。
- LCG の `mod N` による carry `k_i` は小さい範囲に落ちることがあり、総当たり対象にできる。
- 同じ base `m` の複数冪が得られたら、指数の一次結合で `m^1` を作れるかを見る。
