# alloc-101

## 問題の要点

- `free(item)` 後に `item = NULL` されない。
- その後、flag 用の allocation を同サイズで行うと、解放済み `item` と同じ chunk が再利用される。
- `read item` が dangling pointer 経由で flag chunk を読む。

## 解き方

1. flag ファイルと同じサイズで item を allocate。
2. item を free。
3. flag を allocate。
4. item を read すると同じアドレスの flag 内容が出る。

## 知見

- free 後にポインタを残すと Use-After-Free になる。
- tcache/fastbin の基本問題では「同じサイズを再確保して同じ chunk を取る」が第一候補。
