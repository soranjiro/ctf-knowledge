# cat

## 問題の要点

- `/cat?file=...` で指定したファイルを `cat` する。
- `file` に `flag` が含まれると拒否される。
- しかし `subprocess.run(..., stdin=open("flag.txt"))` で flag が標準入力に渡されている。

## 解き方

Linux の `/dev/stdin` を指定すると、`cat` は標準入力として渡された `flag.txt` を読む。

```text
/cat?file=/dev/stdin
```

## 知見

- ファイル名フィルタをしていても、`/dev/stdin`, `/proc/self/fd/*`, symlink, path traversal で別名参照できることがある。
- subprocess に渡した `stdin` は、呼び出し先から通常のファイルディスクリプタとして見える。
